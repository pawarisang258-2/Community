# 🌱 Community Voice Dashboard (เสียงของชุมชน 2566–2567)

Interactive Web Dashboard สำหรับสำรวจและวิเคราะห์ **ความต้องการให้รัฐบาลช่วยเหลือของหมู่บ้าน/ชุมชน 3 อันดับแรก (Top 3)** ในแต่ละจังหวัดทั่วประเทศไทย เปรียบเทียบระหว่างปี พ.ศ. 2566 และ 2567 พัฒนาขึ้นเพื่อช่วยให้นักวิเคราะห์นโยบาย นักศึกษา นักวิจัย และประชาชนทั่วไปสามารถเข้าถึง เข้าใจ และตั้งประเด็นเชิงนโยบายจากข้อมูลความต้องการของชุมชนได้อย่างมีประสิทธิภาพ

---

## 🚀 วิธีการติดตั้งและรัน Dashboard ผ่าน Streamlit

### 1. ติดตั้ง Dependencies
ตรวจสอบว่าเครื่องของคุณมี Python 3.9 ขึ้นไป จากนั้นติดตั้งแพ็กเกจที่จำเป็น:

```bash
pip install -r requirements.txt
```

### 2. รัน Dashboard
รันคำสั่ง Streamlit:

```bash
streamlit run app.py
```

- ระบบจะเริ่ม Local Server และเปิดหน้าเว็บใน Default Browser โดยอัตโนมัติ
- ที่อยู่เริ่มต้น: **[http://localhost:8501](http://localhost:8501)**
- หากพอร์ต `8501` ถูกใช้งานอยู่ Streamlit จะจัดสรรพอร์ตถัดไปให้โดยอัตโนมัติ (เช่น `8502`, `8503`) และแสดงลิงก์ที่ใช้งานจริงใน Terminal ทันที

### 💡 ทางเลือกเสริม: เปิดดูผ่านเบราว์เซอร์โดยตรง (Standalone HTML)
ไฟล์ `index.html` ถูกออกแบบมาให้เป็น Self-contained HTML ที่บรรจุข้อมูล GeoJSON, CSS และ Plotly.js ครบถ้วนในตัว คุณสามารถเปิดไฟล์นี้ได้โดยตรงด้วยเว็บเบราว์เซอร์ (Google Chrome, Microsoft Edge, Safari ฯลฯ) โดยดับเบิลคลิกที่ไฟล์ `index.html` หรือรัน:

```powershell
# บน Windows
Start-Process index.html
```

## 📊 โครงสร้างแท็บและฟังก์ชันการทำงาน

Dashboard ประกอบด้วย 3 แท็บหลัก โดยคงฟังก์ชันและข้อมูลต้นฉบับไว้อย่างครบถ้วน:

### 🗺️ แท็บ 1: ภาพรวมประเทศ (National Overview)
- **KPI Summary Cards:** กลุ่มปัญหาอันดับ 1 บ่อยที่สุด, กลุ่มปัญหาที่กระจายกว้างที่สุด, จำนวนจังหวัดที่เจอปัญหาเดิมทั้งสองปี, และกลุ่มที่มีการเพิ่มขึ้นมากที่สุด
- **Thailand Choropleth Map:** แผนที่ประเทศไทยแสดงกลุ่มปัญหาอันดับ 1 ของแต่ละจังหวัด สามารถคลิกที่จังหวัดเพื่อเจาะลึกได้
- **Treemap สัดส่วนปัญหา:** สัดส่วนความต้องการของชุมชนจำแนกตามกลุ่มปัญหา
- **Region × Issue Heatmap:** ตารางความเข้มข้นของปัญหาในแต่ละภูมิภาค

### 🏡 แท็บ 2: เจาะลึกจังหวัด (Province Deep Dive)
- **ตัวเลือกจังหวัด (Province Selector):** เลือกดูรายละเอียดของแต่ละจังหวัดจาก 77 จังหวัด
- **กราฟปัญหา 3 อันดับแรก (Top 3 Bar Chart):** แสดงร้อยละหมู่บ้าน/ชุมชนตามปัญหาจริง
- **กราฟเปรียบเทียบมัธยฐาน (Median Comparison):** เปรียบเทียบสัดส่วนของจังหวัดที่เลือกกับค่ามัธยฐานของจังหวัดอื่นที่รายงานปัญหาเดียวกันใน Top 3
- **Similar Provinces:** ค้นหาจังหวัดที่มีรูปแบบความต้องการใกล้เคียงกัน
- **Co-occurrence Matrix:** สำรวจกลุ่มปัญหาที่มักพบร่วมกันในจังหวัด
- **Evidence Explorer & Audit Table:** ตารางตรวจสอบข้อมูลความต้องการพร้อมตัวชี้วัดประกอบ 9 กลุ่ม

### 📈 แท็บ 3: การเปลี่ยนแปลงและนโยบาย (Change & Policy)
- **Persistence Matrix:** จำนวนจังหวัดที่กลุ่มปัญหาเดียวกันยังคงอยู่ใน Top 3 ทั้งปี 2566 และ 2567
- **Dumbbell Chart:** เปรียบเทียบการเปลี่ยนแปลงจำนวนจังหวัดที่พบปัญหาใน Top 3 ระหว่างปี 2566 และ 2567
- **Province Tile Grid:** ตารางสถานะรายจังหวัด (คงเดิม, เปลี่ยนบางส่วน, เปลี่ยนทั้งหมด)
- **Policy Explorer & Drill-Down Modal:** สำรวจประเด็นเชิงนโยบายและคลิกดูรายชื่อจังหวัดแบบละเอียด

## 📌 แหล่งข้อมูลและข้อจำกัดการใช้งาน

- **แหล่งข้อมูลหลัก:** สำนักงานสถิติแห่งชาติ เผยแพร่ผ่าน [data.go.th — dataset/0602_00_0002](https://data.go.th/dataset/0602_00_0002)
- **ข้อจำกัดสำคัญ:**
  - ค่า `Per_vill` คือร้อยละของหมู่บ้าน/ชุมชนที่รายงานปัญหานั้น ๆ ต่อจำนวนหมู่บ้าน/ชุมชนทั้งหมดในจังหวัด **ห้ามนำค่าร้อยละมาบวกข้ามปัญหาหรือข้ามจังหวัด**
  - ข้อมูลตัวชี้วัดประกอบ 9 กลุ่มใช้เพื่อเป็นบริบทตั้งประเด็นศึกษา ไม่สามารถนำมาเปรียบเทียบหน่วยกับ `Per_vill` โดยตรงหรือสรุปความเป็นเหตุเป็นผล (Causality)
  - รายละเอียดเพิ่มเติมสามารถอ่านได้ใน [docs/DATA_DICTIONARY.md](docs/DATA_DICTIONARY.md) และ [docs/BRD.md](docs/BRD.md)
