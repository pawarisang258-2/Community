## 1. ภูมิหลังและปัญหา

ข้อมูลความต้องการให้รัฐบาลช่วยเหลือของหมู่บ้าน/ชุมชนเป็นข้อมูลที่ควรนำเสนออย่างเข้าใจง่าย เพื่อดูว่าประเด็นใดปรากฏใน 3 อันดับแรกของจังหวัดต่าง ๆ และรูปแบบดังกล่าวเปลี่ยนไปอย่างไรระหว่างปี 2566–2567 การอ่านตารางดิบอย่างเดียวทำให้เปรียบเทียบจังหวัด กลุ่มปัญหา และช่วงเวลาได้ยาก จึงพัฒนา Interactive Dashboard เพื่อช่วยสำรวจข้อมูลและตั้งประเด็นสำหรับการศึกษาเชิงนโยบายต่อไป

## 2. วัตถุประสงค์

1. แสดงการกระจายเชิงพื้นที่ของปัญหาอันดับ 1 และกลุ่มปัญหาที่อยู่ใน Top 3 ของแต่ละจังหวัด
2. เจาะลึกปัญหาที่รายงานในจังหวัดที่เลือก พร้อมค่าร้อยละของหมู่บ้าน/ชุมชนตามต้นฉบับ
3. เปรียบเทียบค่าของปัญหาเดียวกันกับมัธยฐานของจังหวัดที่รายงานปัญหานั้นใน Top 3 ปีเดียวกัน
4. สำรวจกลุ่มปัญหาที่พบร่วมกันในจังหวัด และจังหวัดที่มีรูปแบบ Top 3 คล้ายกัน
5. เปรียบเทียบจำนวนจังหวัดที่พบกลุ่มปัญหาใน Top 3 ระหว่างปี 2566 และ 2567
6. นำเสนอตัวชี้วัดประกอบอย่างมีบริบท พร้อมสถานะการตรวจสอบและข้อจำกัด
7. เปิดเผยที่มาของข้อมูลและวิธีคำนวณทุกกราฟ ตาราง และ KPI

## 3. ผู้ใช้เป้าหมาย

- นักศึกษา/อาจารย์ที่ต้องการตรวจสอบวิธีวิเคราะห์และข้อมูลอ้างอิง
- ประชาชนที่สนใจความต้องการของชุมชนรายจังหวัด
- ผู้วิเคราะห์นโยบายที่ต้องการใช้เป็นจุดเริ่มต้นของการตั้งคำถาม (ไม่ใช่หลักฐานสรุปสาเหตุ)

## 4. ขอบเขตข้อมูล

### 4.1 ข้อมูลหลัก

- ชุดข้อมูล: **ความต้องการให้รัฐบาลช่วยเหลือประชาชนในหมู่บ้าน/ชุมชน 3 อันดับแรก**
- แหล่งเผยแพร่: [data.go.th — dataset/0602_00_0002](https://data.go.th/dataset/0602_00_0002)
- ผู้จัดทำตามข้อมูลชุดข้อมูล: สำนักงานสถิติแห่งชาติ
- ปีศึกษา: **2566–2567**
- ไฟล์ใน Repository: `data/data_clean_grouped_region.csv` (หากยังอยู่ root ให้ปรับ path ตามจริง)
- คอลัมน์หลักที่ใช้: `year`, `region`, `Need`, `Iss_Need`, `Per_vill`, `Iss_Need_Grouped`, `region_group`
- กลุ่มปัญหา: 9 กลุ่มจากการจัดหมวดหมู่ปัญหาต้นฉบับ; ต้องเก็บตาราง mapping และกฎจัดกลุ่มในเอกสารประกอบ

### 4.2 ข้อมูลตัวชี้วัดประกอบ

- ไฟล์ `group1_...csv` ถึง `group9_...csv` ซึ่งผู้ใช้ได้อัปโหลดขึ้น GitHub
- มีการใช้งานเปรียบเทียบตัวชี้วัดรายจังหวัดกับค่ามัธยฐาน 77 จังหวัดตามไฟล์ Dashboard
- **สถานะ: ยังไม่ผ่านการตรวจยืนยันตัวเลขกับตารางต้นฉบับรายจังหวัด/รายปีครบทุกชุด** แม้โครงสร้างไฟล์อาจครบถ้วน
- ต้องแสดงชื่อชุดข้อมูล หน่วยงาน URL ตารางต้นฉบับ ช่วงปี หน่วย และสถานะการยืนยันสำหรับแต่ละตัวชี้วัด ก่อนอ้างอิงเชิงวิชาการ

## 6. ฟังก์ชันที่ต้องมี

### แท็บ 1 — ภาพรวมประเทศ
- KPI ภาพรวม, Thailand Choropleth Map, Treemap, Region × Issue Heatmap
- ตัวกรองปี (2566/2567), ภูมิภาค, จังหวัด, กลุ่มปัญหา
- คลิกจังหวัดบนแผนที่แล้วเข้าสู่แท็บเจาะลึกจังหวัด พร้อมส่งค่าตัวกรอง

### แท็บ 2 — เจาะลึกจังหวัด
- KPI เฉพาะจังหวัด, กราฟที่ 1 ปัญหา Top 3, กราฟที่ 2 เทียบมัธยฐานจังหวัดที่รายงานปัญหาเดียวกัน
- Evidence Explorer แสดงปัญหาและตัวชี้วัดประกอบ, Similar Provinces, Co-occurrence Matrix, ตาราง Audit
- คลิกช่องเมทริกซ์เพื่อเปิดรายชื่อจังหวัดที่พบคู่กลุ่มปัญหา; คลิกชื่อจังหวัดเพื่อเจาะลึก
- กราฟต้องมีสัดส่วนพอดี ตัวเลขไม่ทับกัน ชื่อแกนชัดเจน รองรับมือถือ

### แท็บ 3 — การเปลี่ยนแปลงและนโยบาย
- Persistence Matrix, Dumbbell Chart เปรียบเทียบ 2566–2567, Province Tile Grid, Policy Explorer
- ห้ามใช้ถ้อยคำว่า “ปัญหาหมดไป” เมื่อไม่พบใน Top 3

### ประสบการณ์ใช้งานและลูกเล่นที่ขอเพิ่ม
- โทนสีสดใสแต่สุภาพ เช่น navy/ม่วงเข้ม + ส้มคอรัล + เขียวมิ้นต์ + ฟ้า + พื้นหลังครีมอ่อน
- ภาพประกอบเชิงแนวคิดเกี่ยวกับเสียงประชาชน ชุมชน เมือง/ชนบท หรือไอคอนเชิงข้อมูล (ต้องมีสิทธิ์ใช้งาน/ระบุเครดิต)
- ปุ่มเปิด/ปิดเสียง (`Sound On/Off`) สำหรับเสียงตอบรับเมื่อผู้ใช้กดแท็บ เลือกจังหวัด หรือเปิดรายละเอียด: ปิดเสียงเป็นค่าเริ่มต้น ห้ามเล่นอัตโนมัติ
- Hover animation, tooltip, micro-interactions, ปุ่ม reset filter, breadcrumb และปุ่มย้อนกลับ
- ปุ่มดาวน์โหลดภาพกราฟ/ข้อมูลที่กรอง (ถ้าพัฒนาได้โดยไม่กระทบประสิทธิภาพ)
- เคารพ `prefers-reduced-motion`, ใช้แป้นพิมพ์ได้, มี contrast เพียงพอ และไม่บังคับใช้เสียง
- ลูกเล่นต้องไม่ทำให้ตัวเลขหรือความหมายทางสถิติเปลี่ยนไป

## 7. ข้อกำหนดแหล่งที่มา — บังคับทุกองค์ประกอบ

**ใต้กราฟ/ตาราง/KPI ทุกชิ้น** ต้องมี Source Footer ที่อ่านได้ชัดเจน โดยประกอบด้วย:

1. **แหล่งข้อมูล:** ชื่อหน่วยงาน + ชื่อชุดข้อมูล + URL ลิงก์ตรง (ถ้ามี)
2. **ช่วงปี:** 2566, 2567 หรือทั้งสองปีตามการแสดงจริง
3. **หน่วย:** ร้อยละหมู่บ้าน/ชุมชน, จำนวนจังหวัด, บาท/เดือน, ดัชนี ฯลฯ ตามตัวชี้วัดจริง
4. **วิธีคำนวณ:** เช่น นับจังหวัดไม่ซ้ำที่พบกลุ่มปัญหาใน Top 3; มัธยฐานเฉพาะจังหวัดที่รายงานปัญหาเดียวกัน
5. **สถานะข้อมูล:** ยืนยันแหล่งต้นทางแล้ว / รอยืนยันค่ารายรายการ / คำนวณจากข้อมูลหลัก
6. **หมายเหตุข้อจำกัด:** กรณีสำคัญ เช่น ร้อยละไม่สามารถบวกกันได้ หรือข้อมูลคนละหน่วย

**ห้าม** ใช้คำกว้าง ๆ ว่า “ที่มา: ข้อมูลภาครัฐ” โดยไม่มีชื่อชุดข้อมูลและลิงก์; ห้ามสร้าง URL อ้างอิงขึ้นเอง หากไม่พบ URL ต้นทางให้แสดง `ยังไม่มีลิงก์ต้นฉบับที่ตรวจสอบได้`

## 8. กฎคำนวณและความถูกต้อง

- `Per_vill` คือร้อยละของหมู่บ้าน/ชุมชนที่รายงานปัญหานั้น **ไม่ใช่สัดส่วนประชากรหรือคะแนนความรุนแรง**
- ห้ามรวม `Per_vill` ข้ามปัญหา/จังหวัดเป็นร้อยละสะสม
- จำนวนจังหวัดที่พบกลุ่มปัญหาใน Top 3 ต้องนับ **จังหวัดไม่ซ้ำ** ภายใต้ปีและตัวกรอง
- อันดับเสมออาจทำให้จังหวัดมีรายการมากกว่า 3 แถว ห้ามตัดทิ้งเพื่อให้เหลือ 3 แถว
- หากไม่พบกลุ่มปัญหาใน Top 3 ปีถัดไป ห้ามสรุปว่าปัญหาหมดไป
- เปรียบเทียบค่ามัธยฐานเฉพาะกลุ่มข้อมูลที่นิยามตรงกันในปีเดียวกัน
- ข้อมูลประกอบและข้อมูลสำรวจต่างหน่วยกัน ห้ามตีความว่าเป็นเหตุผลเชิงสาเหตุหรือหลักฐานยืนยันกันโดยตรง
- ค่า CPI ต้องระวังเรื่องฐานดัชนีและความสามารถในการเปรียบเทียบข้ามพื้นที่
